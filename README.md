# Portafolio — Mariana Hernández

## Descripción

Sitio web de portafolio personal para presentar el perfil profesional, habilidades técnicas y proyectos destacados de Mariana Hernández, desarrolladora Full-Stack Junior. El portafolio incluye una sección de presentación con foto y enlaces de navegación rápida, una sección de habilidades y herramientas, una galería de proyectos destacados con imágenes y tecnologías utilizadas, y una sección de contacto con redes sociales.

## Tecnologías y técnicas utilizadas

- **HTML5** — estructura semántica con etiquetas `<section>`, `<article>`, `<nav>`, `<ul>`, `<li>`
- **CSS3** — diseño responsivo con Flexbox, CSS Grid y posicionamiento absoluto
- **Fuentes web** — Archivo Black y Open Sans mediante `@font-face` (archivos `.woff` y `.woff2`)
- **Diseño responsivo** — tres puntos de ruptura: 1440 px (escritorio), 768 px (tableta) y 320 px (móvil), implementados con `@media`
- **Variables CSS** — tokens de diseño en `:root` para colores, gradientes y espaciado
- **Efectos visuales** — gradientes CSS, `filter: blur()` para elementos decorativos, transiciones en `:hover`
